# 예약 알림 연계 도어락 입력 v2

## 확정 규칙

- 숙소 DB의 `스마트 도어락 여부`를 기준으로 메시지를 분기한다.
- 체크박스 기본값은 `false`이며 일반 도어락으로 처리한다.
- 스마트 도어락 여부와 무관하게 예약 알림에서 Airbnb 고객 전화번호 뒤 4자리를 입력받아 Reservation 원장에 저장한다.
- `false`: 입력값을 그대로 청소 담당자 메시지에도 포함한다.
- `true`: 수집·원장 저장은 수행하고 청소 담당자 메시지에서만 번호 문구를 생략한다.
- JJ House는 `true`다.

## 처리 흐름

```text
RESERVATION_CONFIRMED
→ 운영자에게 Airbnb 전화번호 뒤 4자리 요청
→ 입력값 그대로 Reservation 원장 저장 대상으로 처리
→ Rental Unit의 스마트 도어락 여부 조회
  ├─ true  → 청소 메시지에서 번호 생략
  └─ false → 청소 메시지에 입력값 그대로 포함
```

## 입력값 처리

Airbnb에서 정한 고객 전화번호 뒤 4자리는 운영용 임시값으로 취급한다. 숫자 형식 검사, 반복·연속 번호 거부, 공백 제거, 치환을 하지 않는다. Telegram 답장으로 받은 문자열을 변경하지 않고 메시지에 넣는다.

운영용 Telegram 입력 요청에는 숙소 닉네임, 예약번호, 체크인·체크아웃, 인원, 게스트 결제액, 호스트 수령액을 필수로 표시한다. 이 정보가 빠진 PRODUCTION 요청은 발송하지 않는다.

## 현재 상태

- Rental Unit DB에 `스마트 도어락 여부` 체크박스 추가 완료
- JJ House `true` 반영
- JJ 현재 청소 건의 도어코드 작업 `OWNER_REMOTE / PENDING` 반영
- Python 분기·메시지 조립 단위 테스트 구현
- 실 Bot 답장 수집 활성화 및 원문 보존 TEST 완료
- Codex 연결을 통하지 않는 로컬 Notion 인증은 아직 미설정
- TEST 입력은 Reservation 원장에 쓰지 않으며, 로컬 Notion 인증 후 PRODUCTION 요청만 `출입 코드`에 기록한다.
